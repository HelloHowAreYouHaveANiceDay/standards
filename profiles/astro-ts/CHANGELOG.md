# astro-ts

Astro + TypeScript: ESLint (flat, eslint-plugin-astro recommended + jsx-a11y, typescript-eslint
recommendedTypeChecked on TS, eslint-comments), Prettier + prettier-plugin-astro, `astro check`, exact tool pins
checked offline. Pairs with base.
