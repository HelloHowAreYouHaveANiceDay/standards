# vue-ts

Vue 3 + TypeScript + Vite: ESLint (flat, type-aware: vueTsConfigs.recommendedTypeChecked + eslint-plugin-vue
flat/essential + eslint-comments), Prettier, vue-tsc --build, exact tool pins checked offline. Pairs with base.

## 1.0.0

- First release (prior art: create-vue 3.24.0 defaults, @vue/tsconfig 0.9.1). Pins: eslint 10.14.0, typescript 6.0.3
  (TS 7 has no API yet for typescript-eslint / vue-tsc), vue-tsc 3.3.14, typescript-eslint 8.72.2,
  @vue/eslint-config-typescript 14.9.0, eslint-plugin-vue 10.12.1, eslint-config-prettier 10.1.8,
  @eslint-community/eslint-plugin-eslint-comments 4.8.1, prettier 3.10.0, @vue/tsconfig 0.9.1.
