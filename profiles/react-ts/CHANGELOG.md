# react-ts

React + TypeScript + Vite: ESLint (flat, type-aware: @eslint/js recommended + typescript-eslint
recommendedTypeChecked via projectService + eslint-plugin-react-hooks recommended + react-refresh vite preset +
eslint-comments), Prettier, `tsc --build` over create-vite's app/node tsconfig split, exact tool pins checked
offline. Pairs with base.

## 1.0.0

- First release (prior art: create-vite 9.3.4 `react-ts` template with `--eslint`). Pins: eslint 10.14.0,
  typescript 6.0.3 (TS 7 has no API yet for typescript-eslint), typescript-eslint 8.72.2, @eslint/js 10.0.1,
  eslint-plugin-react-hooks 7.1.1, eslint-plugin-react-refresh 0.5.7, eslint-config-prettier 10.1.8,
  @eslint-community/eslint-plugin-eslint-comments 4.8.1, prettier 3.10.0.
